# 🎓 Student Collaboration Hub

A full-stack web application designed for students to find teammates for projects, hackathons, and assignments based on skill matching.

## ✨ Key Features
- 🔐 **Student Authentication:** Secure Login and Sign-Up system.
- 👤 **Student Profiles:** Customizable profile with skills, university, branch, and bio.
- 📌 **Project Notice Board:** Post project ideas with descriptions, required skills, and team size.
- 🔍 **Skill Search & Filters:** Search candidates and filter project listings in real-time.
- 📨 **Application System:** Project owners can review applicant skills and accept/reject join requests.
- 💬 **Team Workspace Chat:** Real-time project chat for accepted members.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Fetch API, LocalStorage
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Security:** Bcrypt.js (Password Hashing)
